Kondisi Awal

Versi RENTAN

Sistem belum menerapkan kontrol keamanan di luar model LLM. Masukan pengguna digabungkan langsung dengan instruksi sistem tanpa validasi.

  • Instruksi sistem & masukan pengguna bercampur
  • Keluaran model dipercaya 100% tanpa inspeksi
  • Aksi buat_voucher dieksekusi langsung tanpa izin kasir
  • Hasil Uji: Terindikasi Pelanggaran Kebijakan (Jebol)

Kondisi Terproteksi

Versi AMAN

Menerapkan prinsip Defense-in-Depth di mana seluruh kontrol keamanan ditegakkan secara ketat oleh kode aplikasi di luar model LLM.

  • Pemisahan kanal peran (System Instruction terpisah)
  • Isolasi masukan pengguna sebagai data tak tepercaya
  • Allowlist tool ketat (hanya lihat_menu diizinkan)
  • Validasi keluaran: menyaring voucher ilegal & kata terlarang
  • Hasil Uji: Kebijakan Ditegakkan (Aman)

📋 Panduan Pengujian Praktikum (Untuk Penilai / Penguji)

  1. Buka masing-masing versi (Rentan lalu Aman).
  2. Masukkan API Key Google AI Studio milik sendiri (opsi model hemat: gemini-1.5-flash), atau centang Mode Simulasi / Mock Tester jika ingin menguji secara offline tanpa API Key / tanpa kuota token.
  3. Klik tombol "Isi payload serangan" untuk memuat payload prompt injection standar kasus LIVE-1.
  4. Klik tombol "Jalankan payload ×3 & catat ke log".
  5. Perhatikan perbedaannya:
    • Pada Versi Rentan: Sistem terindikasi pelanggaran (merah) karena voucher diskon berhasil diterbitkan.
    • Pada Versi Aman: Sistem menahan serangan (hijau), tool terlarang ditolak oleh kode aplikasi, dan keluaran disanitasi.
  6. Klik "Ekspor log" untuk mengunduh berkas laporan format JSON (24781052-LIVE-1-rentan-log.json dan 24781052-LIVE-1-aman-log.json).
